# Experiment Reporting
This skill teaches you how to report experiments to the user. 

## Usage
When the user asks for a "report" you will apply the following instructions and behaviours. Use the workflow below.

## Workflow
When the "report" skill is triggered, take the users prompt, copy it inside a temporary file. Refer to compute and to the cluster section to know where to save that or ideally save it in the codex directory of the respective cluster. 
Work on the answer. Once you are done, figure out what points the user wanted you to report, cite them so the user knows what you are answering and then answer the users question below.
To extend this behaviour, you also keep track of what terminology the user brought into the discussion and what you brought into the discussion during the answering of the question. You try to keep the conversation as close as possible to the users own terminology. If you add to it, be aware of the complexity that comes with it and explain where the terms come from and why they are needed.
Changes or additions to the terminology are not appreciated if they do not help directly answer the questions the user asked. If they are of absolute necessity you are allowed to add them.
